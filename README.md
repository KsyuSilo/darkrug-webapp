# ДарКруг — веб‑приложение для обмена вещами

ДарКруг — адаптивное веб‑приложение, помогающее людям бесплатно передавать и обменивать вещи, давая им вторую жизнь.

---

## 1. Общие сведения

**Название проекта:** ДарКруг  
**Тип продукта:** веб‑приложение (адаптивный фронтенд)  
**Цель:** предоставить удобный сервис для бесплатной передачи и обмена вещей между людьми.

---

## 2. Целевая аудитория

- Частные лица 18–55 лет.
- Жители крупных и средних городов.
- Пользователи, которые:
  - хотят отдавать вещи в хорошие руки;
  - ищут недорогие или бесплатные вещи;
  - поддерживают осознанное потребление и экоподход.

---

## 3. Платформы и стек

- **Клиент:** HTML5, CSS3, JavaScript.
- **Адаптивность:** смартфоны (≥ 360 px), планшеты, десктопы (≥ 1280 px).
- **Структура фронтенда:**
  - `index.html` — разметка приложения;
  - `styles.css` — стили и адаптив;
  - `app.js` — логика (навигация, фильтры, поиск, пагинация, форма, уведомления, профиль).

Бэкенд и БД специально не фиксируются в рамках данного прототипа и могут быть реализованы позже через REST API.

---

## 4. Основные пользовательские сценарии

### 4.1. Гость

- Просматривает ленту объявлений.
- Фильтрует объявления по категориям.
- Ищет объявления по тексту (заголовок, опционально описание).
- Переключается между лентой и формой добавления объявления.

### 4.2. Автор (будущее расширение)

- Создаёт объявление: заголовок, описание, категория, город, контакты, фото.
- Управляет своими объявлениями (список, редактирование, деактивация).

---

## 5. Интерфейс и UX

### 5.1. Верхняя панель (header)

**Общее:**

- Липкая (sticky), всегда видна.
- Фон — однотонный/градиентный пастельно‑зелёный, без фонового фото.

**Десктопная раскладка:**

- Слева: логотип‑круг с иконкой + название «ДарКруг».
- По центру: строка поиска с иконкой лупы и кнопкой очистки.
- Справа: три круглые кнопки‑иконки:
  - **Дом** — лента;
  - **Плюс** — форма добавления;
  - **Пользователь** — панель профиля.

**Мобильная раскладка:**

- Первая строка: слева логотип+название, справа три иконки.
- Вторая строка: поле поиска на всю ширину.

---

### 5.2. Главный экран (лента объявлений)

**Фильтры категорий:**

- Набор «pill»-кнопок с увеличенными иконками:
  - Все, Дом, Одежда, Книги, Детям, Питомцы, Спорт, Техника, Разное.
- Активная категория подсвечена (цвет, тень, градиент).
- При клике:
  - меняется активное состояние;
  - фильтруется список объявлений по категории.

**Карточки объявлений:**

- Сетка:
  - десктоп: 2–3 карточки в строке;
  - мобильный: 1 карточка в строке.
- Контент:
  - верх: цветной блок с emoji (или будущим фото);
  - низ: заголовок, краткое описание, город и категория.
- При наведении: лёгкое «поднятие» карточки и усиление тени.

**Пагинация:**

- Кнопки «Назад» и «Вперёд» + текст «Страница X из Y».
- Дизейбл на первой/последней странице.
- Реализация на фронтенде (постраничный вывод массива объявлений).

---

### 5.3. Экран добавления объявления

Доступен по кнопке **+** в верхней панели.

**Форма:**

- Блок загрузки фото:
  - область drag & drop;
  - выбор файла;
  - предпросмотр миниатюр.
- Поля:
  - Заголовок — обязательно;
  - Описание — опционально;
  - Категория — выбор через pill‑кнопки;
  - Город — select, обязательно;
  - Контакты — обязательно (произвольная строка).

**Поведение:**

- При нажатии «Опубликовать»:
  - проверка обязательных полей;
  - при успехе — уведомление «Объявление опубликовано»;
  - очистка формы;
  - возврат на экран ленты.
- При нажатии «Отмена»:
  - возврат на экран ленты без сохранения.

---

### 5.4. Панель профиля

Открывается по кнопке **Пользователь**.

- Формат: оверлей с выезжающей панелью снизу (mobile‑first), с затемнением фона.
- Содержимое:
  - аватар‑иконка;
  - имя и статус (город, активность);
  - блок «О себе»;
  - блок контактов (Telegram, email и т.п.);
  - кнопки:
    - «Мои объявления»;
    - «Настройки»;
    - «Сменить город»;
    - «Выйти» (отдельный danger‑стиль).
- Закрытие: по крестику или по клику на затемнённую область.

---

### 5.5. Уведомления

- Маленький всплывающий блок (toast) в правой верхней части экрана.
- Анимация появления/исчезновения (сдвиг + прозрачность).
- Использование:
  - успешная публикация объявления;
  - ошибки валидации (например, не заполнены обязательные поля).

---

## 6. Нефункциональные требования

- Адаптивность для мобильных, планшетов, десктопов.
- Плавные, но быстрые анимации.
- Лёгкий дизайн, без тяжёлых фоновых изображений.
- Минимум зависимостей, всё на чистом HTML/CSS/JS + иконки (Font Awesome).

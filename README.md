# Техническое задание: ДарКруг

## 1. Общие сведения

**Название проекта:** ДарКруг  
**Тип продукта:** Веб-приложение для бесплатного обмена вещами  
**Цель:** Создать платформу, где люди могут отдавать и получать вещи бесплатно, способствуя осознанному потреблению  

---

## 2. Целевая аудитория

- Частные лица от 18 до 55 лет
- Жители городов (Москва, Санкт-Петербург, Новосибирск, Екатеринбург, Казань)
- Люди, которые хотят избавиться от ненужных вещей или найти что-то нужное бесплатно
- Экологически осознанные пользователи, поддерживающие концепцию reuse/recycle

---

## 3. Технологический стек

- HTML5
- CSS3 (с использованием CSS-переменных для тем)
- JavaScript (нативный, ES6+)
- Адаптивная вёрстка (Mobile First)
- Кастомные CSS-анимации

---

## 4. Функциональные требования

### 4.1. Навигация

Верхняя панель (Topbar) содержит:
- Логотип с названием «ДарКруг» (иконка-подарок + текст)
- Поле поиска (по заголовкам объявлений) с иконкой лупы и кнопкой очистки
- Три кнопки навигации:
  - «Лента» (домой) — активна по умолчанию
  - «Создать объявление» (плюс)
  - «Профиль» (пользователь)

**Поведение:**
- Панель остаётся видимой при прокрутке (position: sticky)
- На мобильных устройствах перестраивается в две строки
- Активная кнопка подсвечивается цветом

---

### 4.2. Лента объявлений

**Фильтрация по категориям:**
- Категории: Все, Дом, Одежда, Книги, Детям, Питомцы, Спорт, Техника, Разное
- Активная категория выделяется визуально (белый фон, тень)
- При клике объявления фильтруются с возвратом на первую страницу

**Поиск:**
- Поиск по заголовку в реальном времени (по мере ввода)
- Кнопка очистки (крестик) появляется при наличии текста
- Поиск работает в сочетании с фильтром по категории

**Отображение карточек:**
- Карточка содержит:
  - Слайдер с фотографиями (до 5 шт.) с возможностью перелистывания
  - Кнопки навигации по фото (влево/вправо)
  - Индикаторы-точки для навигации
  - Заголовок
  - Краткое описание (обрезается до 80 символов)
  - Номер телефона продавца
  - Город и категория
- Сетка: 2-3 колонки на десктопе, 1 на мобильных
- При наведении карточка приподнимается (transform)
- Для своих объявлений отображается кнопка удаления (корзина)

**Пагинация:**
- По 6 объявлений на страницу
- Кнопки «Назад» и «Вперёд» с иконками
- Отображение текущей страницы и общего количества

**Детальный просмотр:**
- Клик по карточке открывает модальное окно с полной информацией
- В модальном окне:
  - Увеличенный слайдер с фотографиями
  - Кнопки навигации и индикаторы
  - Счётчик фото (например, "Фото 1 из 3")
  - Полное описание
  - Город и категория
  - Номер телефона продавца
  - Кнопка "Связаться с продавцом" (показывает контакт в уведомлении)
- Закрытие по кнопке-крестику или клику вне модалки

---

### 4.3. Создание объявления

Форма содержит поля:
- **Загрузка фото** (до 5 шт.):
  - Область для загрузки с возможностью выбора файлов
  - Предпросмотр с миниатюрами
  - Возможность удалить каждое фото (кнопка-крестик)
  - Счётчик загруженных фото (0/5)
  - Блокировка загрузки при достижении лимита
- **Заголовок** (обязательное поле)
- **Описание** (текстовое поле, опционально)
- **Категория** (выбор через кнопки-фильтры, активная подсвечивается)
- **Город** (выпадающий список: Москва, Санкт-Петербург, Новосибирск, Екатеринбург, Казань)
- **Номер телефона** (обязательное поле, валидация формата)

**Валидация:**
- Проверка заполнения всех обязательных полей
- Проверка номера телефона (11 цифр, формат +7XXXXXXXXXX)
- Проверка наличия хотя бы одного фото

**Поведение:**
- При успешной публикации — зелёное уведомление и возврат на ленту
- При ошибке валидации — красное уведомление с пояснением
- Кнопка «Отмена» возвращает на ленту без сохранения
- После публикации форма автоматически очищается

---

### 4.4. Профиль

Открывается как выезжающая панель справа с затемнением фона.

**Для неавторизованных пользователей:**
- Поля для ввода имени и номера телефона
- Чекбокс согласия на обработку персональных данных:
  - Текст с выделенными ключевыми словами
  - Ссылка на политику конфиденциальности (всплывающее окно)
  - Обязательное условие для регистрации
- Кнопки:
  - «Войти» — авторизация по имени
  - «Создать аккаунт» — регистрация с проверкой согласия

**Для авторизованных пользователей:**
- Отображение аватара, имени и статуса (город + "Активен")
- Кнопки:
  - «Мои объявления» — фильтрация ленты по своим объявлениям
  - «Настройки» — открывает модальное окно с переключением темы
  - «Сменить город» — диалоговое окно с вводом нового города
  - «Удалить аккаунт» — с подтверждением, удаляет все объявления пользователя
  - «Выйти» — завершение сессии

**Закрытие:** по крестику, клику на затемнение или кнопке "Выйти"

---

### 4.5. Уведомления

- Всплывающий блок в правом верхнем углу
- Три типа:
  - Зелёный (success) — успешные действия
  - Красный (error) — ошибки
  - Жёлтый (warning) — предупреждения
- Автоматически исчезает через 3-4 секунды
- Содержит иконку и текст сообщения

---

### 4.6. Тёмная тема

- Переключение через настройки профиля (чекбокс)
- Сохраняется в LocalStorage
- Изменяет цветовую схему всего приложения
- CSS-переменные обеспечивают плавный переход

---

### 4.7. Управление объявлениями

**Удаление объявления:**
- Доступно только для своих объявлений (в режиме "Мои объявления")
- Кнопка в виде корзины в правом верхнем углу карточки
- Подтверждение удаления через confirm()
- Уведомление об успешном удалении

**Редактирование:** не предусмотрено (можно удалить и создать новое)

---

## 5. Сценарии использования

### 5.1. Просмотр объявлений (гость)
1. Открывает сайт — видит ленту с объявлениями своего города
2. Выбирает категорию или вводит поисковый запрос
3. Листает страницы через пагинацию
4. Кликает по карточке — открывается детальный просмотр с фото
5. Листает фото в карточке и модальном окне

### 5.2. Создание объявления (авторизованный)
1. Нажимает «+» в верхней панели
2. Загружает до 5 фото (с предпросмотром и возможностью удалить)
3. Заполняет заголовок, описание, выбирает категорию и город
4. Вводит номер телефона
5. Нажимает «Опубликовать»
6. Получает уведомление об успехе и переходит в ленту

### 5.3. Регистрация
1. Нажимает иконку пользователя
2. Вводит имя и номер телефона
3. Отмечает чекбокс согласия на обработку персональных данных
4. Нажимает «Создать аккаунт»
5. Получает уведомление об успешной регистрации
6. Автоматически становится авторизованным

### 5.4. Управление профилем
1. Нажимает иконку пользователя
2. Видит своё имя, город и статус
3. Может:
   - Посмотреть свои объявления
   - Сменить город (через диалог)
   - Включить тёмную тему
   - Удалить аккаунт (с подтверждением)
   - Выйти из аккаунта

### 5.5. Работа с фото
1. При создании объявления загружает до 5 фото
2. Видит миниатюры с возможностью удалить каждое
3. После публикации в ленте видит слайдер с фото
4. Может листать фото в карточке через кнопки или точки
5. При клике на карточку видит увеличенный слайдер с фото

## 6. Структура данных

### Объявление (Item):
- Уникальный идентификатор (числовой)
- Заголовок (строка, обязательно)
- Описание (строка, опционально)
- Категория (строка: home, clothes, books, kids, pets, sport, tech, other)
- Город (строка)
- Номер телефона (строка, формат +7XXXXXXXXXX)
- Имя продавца (строка)
- Массив фотографий (до 5 шт., Base64)
- Поля для обратной совместимости (imageData, image)

### Пользователь (User):
- Имя (строка, уникальное)
- Город (строка)
- Номер телефона (строка, формат +7XXXXXXXXXX)

---

## 7. Хранение данных

Все данные сохраняются в LocalStorage браузера:
- `dakrug_items` — массив объявлений
- `dakrug_users` — массив пользователей
- `dakrug_currentUser` — текущий авторизованный пользователь
- `dakrug_city` — выбранный город пользователя
- `theme` — тема оформления (dark/light)

**Особенности хранения:**
- Фото хранятся в формате Base64 (встроенные изображения)
- Размер хранилища ограничен ~5-10 МБ
- При превышении лимита пользователь получит предупреждение

---

## 8. Требования к интерфейсу

### Адаптивность
- Корректно работает на устройствах от 360px
- На мобильных устройствах:
  - Верхняя панель перестраивается в две строки
  - Карточки отображаются в 1 колонку
  - Модальные окна занимают 90% ширины экрана
  - Кнопки слайдера уменьшаются

### Визуальный стиль
- Пастельные тона, зелёные и голубые оттенки
- Скруглённые углы, тени
- Чистый минималистичный дизайн без лишних изображений
- Контрастные элементы для лучшей читаемости

### Анимации
- Плавное появление экранов (fadeIn)
- Анимация выезда уведомлений
- Эффекты при наведении на карточки и кнопки
- Плавное переключение слайдов (0.5s)
- Плавный переход между темами

### Доступность
- Чёткие подписи полей формы
- Визуальные подсказки (placeholder)
- Контрастные цвета для слабовидящих
- Крупные интерактивные элементы

---

## 9. Ограничения и допущения

### Ограничения
- Хранение фото в Base64 ограничивает общий размер данных
- Нет серверной части — все данные хранятся локально
- Нет возможности обмениваться данными между пользователями
- Не поддерживается загрузка файлов других типов (только изображения)

### Допущения
- Пользователь использует современный браузер с поддержкой LocalStorage
- Номер телефона вводится в международном формате (+7XXXXXXXXXX)
- Имя пользователя является уникальным идентификатором
- Город выбирается из предустановленного списка (или вводится вручную)

---

## 10. Планы по развитию (Backlog)

1. **Редактирование объявлений** — возможность изменять существующие
2. **Избранное** — сохранение понравившихся объявлений
3. **Чат между пользователями** — встроенный мессенджер
4. **Расширенный поиск** — фильтрация по цене, дате, району
5. **Геолокация** — автоматическое определение города
6. **Реальные фотографии** — загрузка через сервер (не Base64)
7. **Модерация** — проверка объявлений перед публикацией
8. **Социальный рейтинг** — отзывы о пользователях
9. **Push-уведомления** — о новых объявлениях по подписке
10. **Мобильное приложение** — PWA или нативные оболочки

# Техническое задание: ДарКруг

## 1. Общие сведения

**Название проекта:** ДарКруг  
**Тип продукта:** Веб-приложение для бесплатного обмена вещами  
**Цель:** Создать платформу, где люди могут отдавать и получать вещи бесплатно, способствуя осознанному потреблению

---

## 2. Целевая аудитория

- Частные лица от 18 до 55 лет
- Жители городов
- Люди, которые хотят избавиться от ненужных вещей или найти что-то нужное бесплатно

---

## 3. Технологический стек

- HTML5
- CSS3
- JavaScript (нативный)
- Адаптивная вёрстка
- Font Awesome для иконок
- LocalStorage для хранения данных

---

## 4. Функциональные требования

### 4.1. Навигация

Верхняя панель содержит:
- Логотип с названием «ДарКруг»
- Поле поиска (по заголовкам объявлений)
- Три кнопки: «Лента», «Создать объявление», «Профиль»

Панель остаётся видимой при прокрутке.

### 4.2. Лента объявлений

**Фильтрация по категориям:**
- Категории: Все, Дом, Одежда, Книги, Детям, Питомцы, Спорт, Техника, Разное
- Активная категория выделяется визуально
- При клике объявления фильтруются

**Поиск:**
- Поиск по заголовку в реальном времени
- Кнопка очистки появляется при вводе текста

**Отображение карточек:**
- Карточка содержит: фото (или иконку), заголовок, краткое описание, контакты продавца, город и категорию
- Сетка: 2-3 колонки на десктопе, 1 на мобильных
- При наведении карточка приподнимается

**Пагинация:**
- По 6 объявлений на страницу
- Кнопки «Назад» и «Вперёд»
- Отображение номера страницы

**Детальный просмотр:**
- Клик по карточке открывает модальное окно с полной информацией
- Отображаются все контакты продавца
- Кнопка для связи с продавцом

### 4.3. Создание объявления

Форма содержит поля:
- Загрузка фото (опционально, с предпросмотром)
- Заголовок (обязательно)
- Описание (опционально)
- Категория (выбор через кнопки)
- Город (выпадающий список)
- Контакты (обязательно, проверка формата телефона)

**Поведение:**
- При успешной публикации — уведомление и возврат на ленту
- При ошибке валидации — уведомление с пояснением
- Кнопка «Отмена» возвращает на ленту без сохранения

### 4.4. Профиль

Открывается как выезжающая панель с затемнением фона.

**Для неавторизованных:**
- Поля для ввода имени и контактов
- Кнопки «Войти» и «Создать аккаунт»

**Для авторизованных:**
- Отображение имени и города
- Кнопки:
  - Мои объявления (показывает только свои)
  - Настройки (переключение тёмной темы)
  - Сменить город (диалоговое окно)
  - Удалить аккаунт (с подтверждением)
  - Выйти

**Закрытие:** по крестику или клику на затемнение

### 4.5. Уведомления

- Всплывающий блок в правом верхнем углу
- Зелёный — успех, красный — ошибка
- Автоматически исчезает через 3 секунды

### 4.6. Тёмная тема

- Переключение через настройки профиля
- Сохраняется в LocalStorage
- Изменяет цветовую схему всего приложения

---

## 5. Сценарии использования

### 5.1. Просмотр объявлений (гость)
1. Открывает сайт — видит ленту
2. Выбирает категорию или вводит поиск
3. Листает страницы
4. Кликает по карточке — читает детали

### 5.2. Создание объявления (авторизованный)
1. Нажимает «+» в верхней панели
2. Заполняет форму
3. Нажимает «Опубликовать»
4. Получает уведомление об успехе

### 5.3. Управление профилем
1. Нажимает иконку пользователя
2. Входит или регистрируется
3. Меняет город, просматривает свои объявления, настраивает тему

---

## 6. Структура данных

### Объявление содержит:
- Уникальный идентификатор
- Заголовок
- Описание
- Категорию
- Город
- Контакты (в свободном формате)
- Имя продавца
- Структурированные контакты (Telegram и телефон)
- Фото (в формате Base64) или иконку

### Пользователь содержит:
- Имя
- Город
- Контакты

---

## 7. Хранение данных

Все данные сохраняются в LocalStorage браузера:
- Список объявлений
- Список пользователей
- Текущий пользователь
- Выбранный город
- Тема оформления

---

## 8. Требования к интерфейсу

### Адаптивность
- Корректно работает на устройствах от 360px
- На мобильных верхняя панель перестраивается в две строки

### Визуальный стиль
- Пастельные тона, зелёные оттенки
- Скруглённые углы, тени
- Без изображений в фоне

### Анимации
- Плавное появление экранов
- Анимация уведомлений
- Эффекты при наведении на карточки и кнопки
